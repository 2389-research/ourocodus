## 🛠️ Customization Options

### Change Simulation Parameters

Edit `demo-run.sh`:

```bash
OLD_BASE_LATENCY=250  # Your old avg response time
NEW_BASE_LATENCY=100  # Your new avg response time
NUM_REQUESTS=50       # How many test requests
```

### Use Real API Endpoints

Replace simulation in `demo-run.sh`:

```bash
# Instead of simulate_request(), call your actual API:
latency=$(curl -w "%{time_total}" -o /dev/null -s http://your-api/endpoint)
latency_ms=$(echo "$latency * 1000" | bc)
record_metric "new" "$latency_ms" true
```

### Customize Visualization

Edit `viz-server.go` to:
- Change colors/styling
- Add more metrics
- Customize chart types
- Add your branding

## 📊 Advanced Usage

### Generate Documentation Tables

After running real tests:

```bash
./generate-metrics-table.sh 250 100 450 180 100 300 > METRICS.md
```

Creates markdown with:
- Executive summary table
- Detailed metrics breakdown
- Business impact analysis
- Technical implementation details

### Run Multiple Tests

Compare different optimization strategies:

```bash
# Test 1: No optimization
OLD_BASE_LATENCY=300 ./demo-run.sh

# Test 2: Connection pooling only
OLD_BASE_LATENCY=300 NEW_BASE_LATENCY=150 ./demo-run.sh

# Test 3: Pooling + batching
OLD_BASE_LATENCY=300 NEW_BASE_LATENCY=100 ./demo-run.sh
```

### Export Metrics

Visualization server exposes API:

```bash
# Get all metrics
curl http://localhost:9090/api/metrics

# Get stats
curl http://localhost:9090/api/stats
```

Use for:
- Automated reporting
- CI/CD integration
- Historical tracking
